# 💻 CMNS Fix Mac (cmnsfixmac.com)

ระบบเว็บไซต์สำหรับร้านซ่อม Mac และจำหน่ายอะไหล่ (CMNS Fix Mac)
โปรเจกต์นี้พัฒนาเพื่อใช้บริหารจัดการสินค้า, งานซ่อม และหน้าบ้านสำหรับลูกค้า

## 🚀 ฟีเจอร์หลัก
- **Shop System:** ระบบจัดการสินค้า อะไหล่ และสต็อก
- **Admin Dashboard:** หลังบ้านสำหรับจัดการรายการสินค้าและ Order
- **Service/Warranty:** ระบบเช็คประกันและสถานะงานซ่อม

## 🛠️ Tech Stack
- **Language:** PHP
- **Frontend:** HTML, CSS, JavaScript (Bootstrap/Custom CSS)
- **Database:** MySQL
